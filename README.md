# Pecantet Arquitetura

Landing page institucional da Pecantet Arquitetura, desenvolvida com foco mobile-first.

## Destaques

- identidade visual em preto, cinza e branco;
- portfólio e apresentação institucional;
- seção dedicada a projetos sustentáveis;
- navegação responsiva;
- contato direto pelo WhatsApp;
- logo oficial com fundo transparente e imagens integradas ao projeto.

## Executar localmente

O site é estático. Sirva a pasta `dist` com qualquer servidor HTTP local.
